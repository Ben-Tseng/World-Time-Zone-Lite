🌍 World Time Zone Lite
A lightweight, interactive timezone comparison tool inspired by World Time Buddy. Built with vanilla HTML, CSS, and JavaScript.

✨ Features
Real-time timezone visualization – See multiple cities across a 24-hour timeline

Interactive grid – Hover over any hour to highlight the entire column across all locations

Add/remove locations – Search from a built-in city database and manage your list

Date navigation – Jump between days (6-day range) with a visual date strip

Automatic time difference badges – See offset hours relative to the first location (marked as "home")

Night/day & weekend styling – Visual cues for off-hours and weekends

Live clock updates – Times refresh automatically every minute

Responsive & clean UI – Modern design with Inter font and minimalist styling

🛠️ How to Use
Add a city: Click the + icon or type in the search box to find and add a new location

Remove a city: Hover over a location row and click the × button that appears

Change date: Click any date in the strip, or use the calendar icon to pick a specific date

Compare times: Hover over the timeline to see a vertical highlight across all cities for that hour

Understand the view:

First location is considered "home" (marked with a house icon ⌂)

Other locations show an offset badge (e.g., +5) indicating hours ahead/behind home

Night hours (10 PM – 6 AM) are shaded darker

Weekend days are tinted orange in the date strip
